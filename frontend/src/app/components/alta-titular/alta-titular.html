Alta de Titular

Complete los datos requeridos para registrar un nuevo titular en el sistema.

Datos Personales

El tipo es requerido.
El número debe tener 8 dígitos.
El nombre es requerido.
El apellido es requerido.
La fecha es requerida. El titular debe ser mayor de 18 años.

Domicilio

La calle es requerida.
Ingrese un número válido.
Debe tener exactamente 4 dígitos.
La localidad es requerida.
La provincia es requerida.

Datos Adicionales

La clase es requerida.
El grupo sanguíneo es requerido.
